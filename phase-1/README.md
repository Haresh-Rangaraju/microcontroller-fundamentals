# Microcontroller Fundamentals

This repository contains notes and learning material related to microcontroller fundamentals.

## Topics Covered

* Introduction to Microcontrollers
* CPU Architecture
* Registers
* Memory Map
* GPIO
* Interrupts
* Timers
* ADC
* UART
* SPI

The goal of this repository is to understand how microcontrollers work and how software interacts with hardware in embedded systems.

Each topic may contain:

* Interface explanations
* Interview-oriented notes
